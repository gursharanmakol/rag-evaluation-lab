# Changelog

## 2026-09-22 - Evaluation and trace tools
Added the evaluation set and the evaluate command, with recall@3, recall@10
and MRR. Added inspect for live questions and trace for logged conversations.

## 2026-08-24 - Support assistant retrieval
Added search over help-center sections with a bundled embedding model, a
keyword reranker, and prompt assembly under a 500-token context budget.
